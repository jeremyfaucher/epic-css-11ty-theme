Use both to give a page a clear visual order. ---

A change in size, weight or color can draw attention to an important detail. Choose the detail first, then decide how much visual difference it needs beside the surrounding content.

Give contrast a specific job

Repeat a few visual choices across the page. Consistent shapes, type styles and gaps can connect sections while allowing important elements to stand out.

Shared spacing and type styles give separate sections something in common. Repetition can create harmony without making every section identical or removing useful differences between the parts of a page.

A small break in a repeated pattern can create tension. Use that interruption deliberately, and check that it supports the reading order rather than distracting from the main content.
