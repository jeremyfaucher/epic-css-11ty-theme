A category label can appear in a sidebar, a breadcrumb and a page introduction. Check each place that uses the record after an edit, rather than assuming that one correct page proves every surface is ready.

Verify the shared surfaces

Treat performance as something to measure with a built page. Source structure and build options explain the approach, but they do not replace checking the result.

The theme embeds minified CSS in the page, and its build tools offer a separate filtering step. These mechanisms affect delivery, but they do not establish a speed score or remove the need to review image sizes.

Use semantic headings and navigation, then inspect keyboard access and reading order in context. Shared templates make fixes easier to repeat; they do not by themselves prove that a finished site meets an accessibility standard.
