Use consistent spacing for related sections and larger pauses when the topic or purpose changes. ---

A repeated space between headings and paragraphs creates a familiar pattern. Readers can move through that pattern without having to work out the relationship between elements in every new section.

Let spacing support reading

Allow room for a pause between topics. A larger gap can mark a transition without introducing another color, border or heading style into the layout.

Use a larger gap to separate groups that introduce a different topic. The change in rhythm can help readers notice a transition while keeping the same typography and alignment across the page.

Test repetition with real differences in content length. A short heading and a long heading should both fit the pattern without forcing every card or section to contain the same number of words.
