This starter combines Eleventy content templates with Epic CSS utility classes. Pages are built from files in the source directory, with shared includes for navigation, article layouts and listings. The sample content gives those templates enough variety to inspect how headings, paragraphs and images work together before adapting the theme for another site.

How the theme fits together

Category details live in a shared data file. Each record supplies its label, URL and collection name, along with introduction text and landing-page metadata. The sidebar and breadcrumbs read those records. Keeping these related values together reduces the number of places to edit when a category changes, while the page templates retain a common structure.

Post content stays in individual files, with titles, dates and descriptions in front matter. Directory data connects posts to their category and collections. Category landing pages select a collection and show posts in reverse order. The blog index uses the combined collection, so a new article can appear in more than one listing without duplicating its body text.

The layout uses utility classes for spacing, alignment and responsive grids. A wider screen places category navigation beside the post list; a narrow screen stacks the same content in reading order. These choices provide a starting point for a site. Check long headings, keyboard navigation and images with the content that will actually be published.

Consistency comes from useful repetition. Reuse a heading style or spacing pattern where it expresses the same relationship, and change it when the content needs a different level of emphasis.

The build prepares HTML and minifies the embedded CSS. A separate filtering command can reduce the stylesheet to matching utilities. Measure the result with real content rather than treating a build step as a guarantee of speed.
